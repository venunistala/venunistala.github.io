# venunistala.github.io

Personal portfolio for an SDET / test platform engineer. The site is both the
artifact and the evidence: it ships behind its own Playwright + axe gate.

## Stack

Next.js App Router (static export) · TypeScript strict · Tailwind · MDX ·
Playwright · @axe-core/playwright · Vitest · pnpm · GitHub Actions → Pages

## Hard rules

- Static export only. No server components with runtime data, no API routes,
  no `dynamic = 'force-dynamic'`.
- GitHub USER site at the domain root. Never add basePath or assetPrefix.
- `public/.nojekyll` must survive every build.
- No component libraries. Tailwind + local components only.
- No localStorage or sessionStorage.
- Zero axe violations is a build gate, not a goal. Do not add `disableRules`
  to make a test pass — fix the markup.
- No metric, client name, or logo appears on this site unless it came from the
  factual master resume. If unsure, ask; do not infer.

## Testing philosophy

- Playwright runs against the built static export, never `next dev`. We test
  what ships.
- Every route gets an axe scan. Violations fail the run.
- Assertions must be deterministic: no fixed sleeps, no hardcoded dates, no
  assumptions about parallel execution order.
- `quality.json` is generated by CI from real run output. Never hand-edit it.

## Commands

pnpm dev · pnpm build · pnpm lint · pnpm test · pnpm test:e2e

## Before saying a task is done

Run `pnpm lint && pnpm build && pnpm test && pnpm test:e2e`. Report actual
output, not intent.
